# GhostSeg Technical Registry

Status: v0.1
Data-base: 2026-06-24
Repositório: `ghosolutions/roadmap`

## Objetivo

Esta pasta consolida o CMDB técnico do ecossistema GhostSeg, conectando repositórios, agentes, prompts, artefatos, conectores, projetos e diagramas versionáveis.

## Arquivos

| Arquivo | Finalidade |
|---|---|
| `technical-registry.md` | Índice executivo do registry técnico |
| `inventario-repositorios.md` | Classificação dos repositórios GhostSeg |
| `catalogo-agentes.md` | Catálogo inicial de agentes e automações |
| `catalogo-prompts.md` | Catálogo inicial de prompts por domínio |
| `mermaid/universe-map-v2.mmd` | Mapa Mermaid versionável do ecossistema |
| `mermaid/dependency-map-v1.mmd` | Mapa Mermaid de dependências principais |

## Regra de governança

Todo repositório, agente, prompt ou artefato técnico relevante deve ter ID e vínculo com projeto, status e dependências. Sem registry, vira arqueologia digital.
